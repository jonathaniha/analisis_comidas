# McDonald's Menu Nutrition & Dietary Analysis

An exploratory data analysis (EDA) and interactive dashboard project analyzing the nutritional composition of the McDonald's menu, featuring custom dietary filters for healthy food and breakfast alternatives.

## Features

- **Nutritional Exploration:** Calorie, fat, and macronutrient profile analysis across menu items.
- **Dietary Pre-filtering:** Dedicated datasets and filters for health-conscious meals and breakfast selections.
- **Interactive UI Support:** Designed for interactive data visualization with Streamlit.

## Repository Structure

- `proyecto.py`: Core data processing, analysis scripts, and visualization routines.
- `requirements.txt`: Environment dependencies for reproducible deployment.
- `*.csv`: Ingested McDonald's nutrition datasets and curated dietary sub-tables.

## Technologies & Dependencies

- **Language:** Python 3.x
- **Libraries:** [Pandas](https://pandas.pydata.org/), [Streamlit](https://streamlit.io/)
